# Tables

All tables from the TRIAD-BRCA+ manuscript, numbered as in the paper. Each table is a UTF-8 CSV file; `All_Tables.xlsx` holds all 24 with captions and notes.

| File | Caption |
|---|---|
| [Table_1.csv](Table_1.csv) | **Table 1.** Data sources and their role in the study. |
| [Table_2.csv](Table_2.csv) | **Table 2.** Leakage governance: variable categories excluded before any modelling, and the retained clinical view. |
| [Table_3.csv](Table_3.csv) | **Table 3.** Knowledge-guided meta-gene modules (fixed a priori), with descriptive mean scores by subtype (standardised units) and Kruskal–Wallis tests on the full core-4 cohort. |
| [Table_4.csv](Table_4.csv) | **Table 4.** Hyper-parameters, search spaces and the values selected by inner cross-fitting. |
| [Table_5.csv](Table_5.csv) | **Table 5.** Characteristics of the analytical METABRIC cohort by PAM50 subtype (core-4, n = 1,559). *Note:* *Receptor status is shown descriptively and is never used as a predictor. p: Kruskal–Wallis (continuous) or χ² (binary). |
| [Table_6.csv](Table_6.csv) | **Table 6.** Leakage audit over the 10 paired folds. Each excluded channel is re-inserted into the honest full-panel representation and scored with three probes; parentheses give the change in balanced accuracy versus the honest pipeline (percentage points, corrected resampled t-test). L5 repeats the v1 preprocessing-leakage experiment with the v1 SVM expert. The last column quantifies metric-substitution optimism. |
| [Table_7.csv](Table_7.csv) | **Table 7.** Performance on core-4 PAM50 subtyping (METABRIC, repeated 5-fold CV × 2, mean ± SD over 10 paired folds). All models share identical fold indices. *Note:* The arg-max operating point is the same fitted TRIAD-BRCA+ model without the balanced-risk rule (ablation step A4). |
| [Table_8.csv](Table_8.csv) | **Table 8.** Paired comparison of TRIAD-BRCA+ with every comparator over the 10 folds: mean difference and Nadeau–Bengio corrected resampled t-test, Holm-adjusted within each configuration and metric; effect size, Wilcoxon test and win/tie/loss counts refer to balanced accuracy. *Note:* p_Holm: Nadeau–Bengio corrected resampled t-test, Holm-adjusted within each configuration and metric. W/T/L: folds won/tied/lost by TRIAD-BRCA+. |
| [Table_9.csv](Table_9.csv) | **Table 9.** Incremental ablation from TRIAD-BRCA v1 (A0) to TRIAD-BRCA+ (A5). Each step adds one component; p: corrected resampled t-test on ΔBA, Holm-adjusted over the five steps. |
| [Table_10.csv](Table_10.csv) | **Table 10.** Leave-one-component-out analysis of TRIAD-BRCA+ (p: corrected resampled t-test, Holm-adjusted). |
| [Table_11.csv](Table_11.csv) | **Table 11.** Fusion × decision analysis on identical expert fits (cells: Balanced accuracy / MCC, mean of 10 folds). The proposed configuration is the equal-weight linear pool with the balanced-risk (λ = 1) rule. *Note:* Cells: Balanced accuracy / MCC (mean of 10 folds). Bold cell in Figure 7 = proposed configuration. |
| [Table_12.csv](Table_12.csv) | **Table 12.** Mean BE-adaptive routing weights (v1 Eqs. 5–7) assigned to the TRIAD-BRCA+ experts, by Boundary-Energy stratum (all 10 outer test folds). |
| [Table_13.csv](Table_13.csv) | **Table 13.** Per-subtype performance on pooled out-of-fold predictions (repeat 1; every patient predicted once, n = 1,559). 95% CIs: 1,000 bootstrap resamples. |
| [Table_14.csv](Table_14.csv) | **Table 14.** Probability calibration on pooled out-of-fold posteriors (lower is better). For TRIAD-BRCA+ the fused posterior is evaluated; the balanced-risk rule changes decisions, not probabilities. |
| [Table_15.csv](Table_15.csv) | **Table 15.** Permutation importance (model reliance) of TRIAD-BRCA+ on outer test folds of repeat 1: view-level (5 permutations) and the 20 most important individual features (2 permutations). |
| [Table_16.csv](Table_16.csv) | **Table 16.** Error diversity of the expert triads on pooled out-of-fold predictions (lower Q / error correlation = more complementary). |
| [Table_17.csv](Table_17.csv) | **Table 17.** Robustness to degraded molecular input at inference (5 folds of repeat 1, balanced accuracy mean ± SD). Mutation calls are randomly lost; RNA values receive Gaussian noise or are set missing. |
| [Table_18.csv](Table_18.csv) | **Table 18.** Learning curves: Balanced accuracy (mean ± SD over the 5 folds of repeat 1) versus the number of training patients. |
| [Table_19.csv](Table_19.csv) | **Table 19.** Clinical validity: prognostic stratification by reference PAM50 labels versus out-of-fold predicted subtypes (univariable Cox models, Luminal A reference; hazard ratio (HR) with 95% CI). |
| [Table_20.csv](Table_20.csv) | **Table 20.** External TCGA-BRCA cohort characteristics. The multi-omics export carries no patient barcodes, so the GDC clinical export is summarised at cohort level only. |
| [Table_21.csv](Table_21.csv) | **Table 21.** Cross-cohort transfer METABRIC → TCGA-BRCA (harmonised panel: 22 RNA + 44 mutation genes; IHC-surrogate 3-class reference, n = 506; true distribution TN/HER2/Lum = 90/86/330). 95% CIs: 1,000 bootstrap resamples. |
| [Table_22.csv](Table_22.csv) | **Table 22.** Headline comparison. The re-run column uses the identical folds and the stricter leakage governance of this study; the TCGA rows compare the v1 protocol (E1) with the proposed harmonised protocol (E3). |
| [Table_23.csv](Table_23.csv) | **Table 23.** Answers to the research questions (RQs) and the supporting evidence. *Note:* pp: percentage points; ECE: expected calibration error; MCC: Matthews correlation coefficient; IHC: immunohistochemistry. |
| [Table_24.csv](Table_24.csv) | **Table 24.** Comparison with recent (2024–2026) state-of-the-art studies of breast-cancer molecular subtype classification. Performance values are those reported by the original authors. *Note:* Values were obtained under each study’s own cohort, label set, data views and protocol and are not directly comparable with each other or with TRIAD-BRCA+. BA: balanced accuracy; CV: cross-validation; ECE: expected calibration error; IHC: immunohistochemistry; LR: logistic regression; MCC: Matthews correlation coefficient; SVC: support vector classifier. |
