# Data

The five input files are public but are **not redistributed here**; download them from their original sources (each has its own terms of use) and place the CSV files in this folder, or upload them when the notebook asks.

| Manuscript ref. | File name the notebook expects | Source |
|---|---|---|
| [86] | `METABRIC_RNA_Mutation.csv` | https://www.kaggle.com/datasets/raghadalharbi/breast-cancer-gene-expression-profiles-metabric |
| [87] | `Breast_Cancer_METABRIC.csv` | https://www.kaggle.com/datasets/gunesevitan/breast-cancer-metabric |
| [88] | `brca_metabric_clinical_data.csv` | https://www.cbioportal.org/study/summary?id=brca_metabric |
| [89] | `brca_data_w_subtypes_tcga.csv` | https://www.kaggle.com/datasets/samdemharter/brca-multiomics-tcga |
| [90] | `clinical_-_clinical_tcga.csv` | https://portal.gdc.cancer.gov/projects/TCGA-BRCA |

The notebook matches files by name pattern (`*METABRIC_RNA_Mutation*.csv`, `*Breast_Cancer_METABRIC*.csv`, `*brca_metabric_clinical_data*.csv`, `*brca_data_w_subtypes_tcga*.csv`, `*clinical_tcga*.csv`), so keep these names when you save the downloads.

See Table 1 of the manuscript ([Tables/Table_1.csv](../Tables/Table_1.csv)) for what each file contributes.
